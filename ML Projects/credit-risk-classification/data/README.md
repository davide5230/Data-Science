# Data

This project uses the Credit Risk Dataset available on Kaggle:

https://www.kaggle.com/datasets/laotse/credit-risk-dataset

Download the dataset from the original source and place the required CSV file in this directory.

The dataset is not redistributed here in order to keep a clear separation between source data and portfolio code.

If the downloaded filename differs from the path expected by the notebook, update the dataset path before running the analysis.
